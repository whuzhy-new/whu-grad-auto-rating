# 🎓 WHU 一键评教（研究生版）

> 专为**武汉大学研究生**打造的评教自动化插件，一键搞定所有待评课程，全部满星提交，从此告别重复点击的痛苦。

## 这是什么？

每学期评教季，十几门课、每门课五六个评分项，挨个点五星再提交——光是想想手指就累了。

这个 Chrome 插件帮你**一键完成所有待评课程的评教**：自动打满星、自动提交、自动切换下一门，直到全部搞定。你只需要点一下按钮，然后看着它刷刷刷跑完。

## 适用范围

- **仅限武汉大学研究生评教系统**（`http://newyjs.whu.edu.cn/`）
- 本科生评教系统不适用

## 安装（30 秒搞定）

支持 **Chrome** 和 **Edge**（所有 Chromium 内核浏览器均可）。

1. [下载本仓库](https://github.com/whuzhy-new/whu-grad-auto-rating/archive/refs/heads/main.zip) 并解压
2. 打开扩展管理页：
   - Chrome：地址栏输入 `chrome://extensions/`
   - Edge：地址栏输入 `edge://extensions/`
3. 开启「**开发者模式**」（Chrome 右上角 / Edge 左侧栏）
4. 点击「**加载已解压的扩展程序**」→ 选择解压后的文件夹
5. Done!

## 使用方法

1. 正常登录研究生评教系统 http://newyjs.whu.edu.cn/
2. 进入评教页面（能看到「待评」/「已评」标签的那个页面）
3. 页面右下角会自动出现一个蓝色按钮：**「一键全部评教」**
4. 点它，然后坐等就行

插件会自动循环执行：

```
点击「待评」→ 进入第一门课 → 全部五星 → 提交 → 回到列表 → 进入下一门 → ...
```

全部完成后按钮会显示「全部评教完成！共 X 轮」。

## 运行状态

按钮会实时告诉你在干什么：

| 显示内容 | 含义 |
|---------|------|
| `第 X 轮: 点击待评...` | 正在切换到待评列表 |
| `第 X 轮: 进入待评项...` | 正在打开课程评教页 |
| `第 X 轮: 打五星...` | 正在给所有项目评满分 |
| `第 X 轮: 提交...` | 正在提交本门课程 |
| `全部评教完成！共 X 轮` | 大功告成 |

## 注意事项

- 运行期间**不要手动操作页面**，让插件跑完
- 如果网速慢导致超时停住了，刷新页面重新点按钮即可
- 插件仅在 `newyjs.whu.edu.cn` 域名下生效，不会影响其他网站

## 停用 / 卸载

评教季结束后建议停用或删除插件，避免占用浏览器资源。

**临时停用（保留插件，下次可快速启用）：**
- Chrome：`chrome://extensions/` → 找到「WHU 一键评教」→ 关闭右下角开关
- Edge：`edge://extensions/` → 找到「WHU 一键评教」→ 关闭开关

**彻底卸载：**
- 在扩展管理页点击「移除」即可，不会残留任何数据
